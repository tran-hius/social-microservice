# 🎯 Meaningful Code Coverage

## 1. Nguyên tắc về Độ Phủ (Coverage Principles)
- **100% Line Coverage không đồng nghĩa với 0 lỗi**: Không viết test chỉ để tăng % coverage mà không assert kết quả thực tế.
- **Ưu tiên kiểm thử các nhánh rủi ro cao (Branch Coverage)**:
  - Logic xác thực, phân quyền, bảo mật.
  - Các nhánh xử lý ngoại lệ (Catch error paths).
  - Các phép tính toán tài chính, trạng thái đơn hàng/bài viết.
