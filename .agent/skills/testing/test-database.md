# 🗄️ Test Database & Fixtures

## 1. Quản lý Dữ liệu Mẫu (Fixtures & Factories)
- Sử dụng Factory Functions để sinh dữ liệu mẫu có cấu trúc hợp lệ thay vì copy-paste object JSON thô.

## 2. Làm sạch Dữ liệu Test (Data Cleanup)
- Luôn dọn dẹp dữ liệu sau khi kết thúc test suite để tránh làm ảnh hưởng đến các ca test tiếp theo (Tránh Flaky Tests).
