# 🧹 Maintainability & Clean Code Review

## 1. Tiêu chuẩn Đọc & Bảo trì
- **Comment thừa**: Có những comment giải thích lại đúng những gì code đang làm không? *(Yêu cầu xóa)*.
- **Magic Strings / Numbers**: Các hằng số (ví dụ thời hạn token, role enum, status code) có được định nghĩa thành constant/enum không?
- **Đặt tên (Naming)**: Tên hàm, biến có thể hiện đúng ý nghĩa và hành vi không?
- **DRY (Don't Repeat Yourself)**: Có logic trùng lặp có thể tái sử dụng không?
